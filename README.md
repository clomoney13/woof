# Woof — Best in Show (prototype)

A browser-based prototype of a hybrid-casual sliding-puzzle mobile game concept: slide colorful dachshunds to their matching rosette. Built as a single-file HTML/CSS/JS prototype to validate the core mechanic before a Unity port.

Open `index.html` in any browser to play.

## What's in here
- 5 levels + a chained "boss round" puzzle
- Level map with progress avatar
- Move-limit goals, boosters, collectible treats, combo scoring
- Placeholder ad/booster hooks marking where real SDK integration goes

## Next steps
- Port core mechanic + level format to Unity
- Replace CSS-drawn art with real illustrated assets
- Real ad SDK (AdMob/AppLovin) integration at the marked placeholder points
